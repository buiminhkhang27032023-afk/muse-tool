1 · Chọn người chơi

Mỗi tab trình duyệt đã nối (một tài khoản ChatGPT, Gemini, Claude, Grok, Muse...) và mỗi bot webhook/API là một người chơi. Tick ít nhất 2. Vai là câu mô tả tính cách (không bắt buộc).

Chưa có tab nào nối. Mở ChatGPT, Gemini, Claude, Grok hay Muse ở trình duyệt đã cài extension (xem Nối trình duyệt), hoặc thêm bot bên dưới.

2 · Mở phòng

Bot webhook / API

Dùng cho Grok hoặc bất kỳ bot nào bạn có đường nối. Webhook: Tool POST JSON tới địa chỉ của bạn, bạn trả {"reply":"...", "images":[...], "options":[...]}.

+ Thêm bot

Bot CLI sẽ tự sửa file / chạy lệnh thật trong thư mục này. Để trống = thư mục của Tool. Gõ [DIR: đường dẫn] ở đầu tin nhắn khi giao việc để đổi thư mục riêng cho lượt đó.
